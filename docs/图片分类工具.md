# 图片分类工具

## 工具定位

图片分类工具是数据准备工具，不是商家后台。

它的作用是把本地的酒包装案例图片整理成小程序可以使用的数据：压缩后的图片文件和 `cases.json`。

## 工作流程

1. 选择本地图片文件夹。
2. 工具读取 `.jpg`、`.jpeg`、`.png` 图片。
3. 按稳定顺序排序并自动编号：
   - `case_001`
   - `case_002`
   - `case_003`
4. 逐张查看图片。
5. 给图片选择分类标签。
6. 浏览器自动保存标注进度。
7. 导出压缩后的 JPG 图片和 `cases.json`。
8. 后续再把图片上传微信云存储，并把 fileID 写回 JSON。

## 分类规则

必选：

- 酒类
- 包装内容

可选：

- 风格
- 使用场景
- 价位感
- 工艺
- 状态
- 标题
- 备注
