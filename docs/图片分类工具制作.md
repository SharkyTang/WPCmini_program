```text

```

## 项目结构

```text
index.html

package.json
tests/case-classifier.test.mjs
README.md
```

## 核心能力

- 本地选择图片文件夹。
- 支持 `.jpg`、`.jpeg`、`.png`。
- 自动生成 `case_001` 形式的编号。
- 原图不重命名、不覆盖、不删除。
- 手动点选分类标签。
- 标注进度保存到浏览器本地存储。
- PNG 透明区域导出为白底 JPG。
- 图片最长边压缩到 1600px。
- JPG 质量为 0.85。
- 导出 `cases.json` 和压缩图片。

## 已确认的规则

- 只有 `酒类` 和 `包装内容` 是必选。
- 标题不是必填。
- 风格、场景、价位感、工艺、状态都可选。
- 不做微信云存储上传。
- 不做数据库导入。
- 不做 AI 自动分类。
- 不做商家登录权限。
