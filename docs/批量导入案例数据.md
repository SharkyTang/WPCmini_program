# 批量导入案例数据

这个脚本用于把本地分类工具导出的数据导入 CloudBase：

- 读取 `export/cases.json`
- 检查 `export/optimized-images/` 中的图片是否存在
- 上传图片到云存储
- 写入 `wine_packaging` 集合

## 第一步：先 dry-run

```bash
npm run import:cases:dry
```

dry-run 只检查文件和预览将要写入的数据，不会上传图片，也不会写数据库。

## 只测试前 10 条

```bash
node scripts/import-wine-packaging.mjs --limit 10 --dry-run
```

## 真实导入前

先安装 CloudBase Node SDK：

```bash
npm install @cloudbase/node-sdk
```

再设置腾讯云访问密钥：

```bash
export TENCENTCLOUD_SECRET_ID="你的 SecretId"
export TENCENTCLOUD_SECRET_KEY="你的 SecretKey"
```

然后执行：

```bash
npm run import:cases
```

## 默认配置

- 云环境：`cloud1-d3gznsms746425a42`
- 集合：`wine_packaging`
- 图片目录：`export/optimized-images`
- 数据文件：`export/cases.json`
- 云存储路径：`wine-packaging/cases/`

## 写入字段

脚本会把分类工具导出的数组字段转换成 CMS 当前使用的 Json 格式：

```json
{
  "packageTypes": { "values": ["礼盒", "瓶子"] },
  "styles": { "values": ["国潮"] },
  "scenes": { "values": ["送礼"] }
}
```

`coverImage` 会使用上传后返回的云存储 fileID。
