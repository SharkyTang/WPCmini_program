# 小程序规划

## 产品方向

产品名称：酒包装设计分类小程序。

第一阶段服务自己家的私人定制酒包装设计店，未来再扩展给更多商家使用。

## 用户和痛点

客户痛点：

- 设计店案例图很多，通常堆在朋友圈或文件夹里。
- 客户想找特定参考图，需要反复翻找。
- 客户经常想把几个案例的风格组合起来表达需求。

商家痛点：

- 不知道如何系统分类和展示案例。
- 第一次沟通到成交之间等待时间长。
- 很多沟通时间浪费在“找图”和“解释风格”上。

## v1 范围

先做一个能展示和筛选案例图的小程序，不做复杂商家后台。

v1 必须有：

- 客户可以看到案例图。
- 客户可以按分类筛选案例。
- 数据先来自已经整理好的 89 张图。
- 图片存微信云存储。
- 案例信息存在云数据库。

v1 不做：

- 多商家入驻。
- 商家手机端上传。
- AI 自动识别分类。
- 成交转化率统计。
- 在线生成设计图。

## 后续版本

v2：完善筛选、搜索、详情页和收藏/参考图功能。

v3：加入电脑端商家上传图片和编辑分类。

v4：支持客户选择多张参考图，生成需求描述。

v5：扩展多商家、多店铺和权限。

## 当前关键判断

第一版不是先做完整平台，而是先把自己家的案例图整理好，让客户更快找到参考方向。
